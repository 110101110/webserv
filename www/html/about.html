A web server
written in C++98

Built from scratch without any external library. Handles HTTP/1.1, non-blocking I/O with poll(), CGI execution, file uploads, and virtual hosting.

⚡

Non-blocking I/O

Single-threaded event loop using poll(). Handles hundreds of concurrent connections without blocking.

🔀

CGI Support

Executes Python scripts via fork() + execve(). CGI processes are supervised with a 7-second timeout.

📤

File Upload

Supports multipart/form-data and raw body uploads. Files are saved to a configurable upload_store directory.

🌐

Virtual Hosts

Multiple servers on the same port, differentiated by the Host header. Nginx-like configuration file.
