Implemented Features
Everything this server supports, tested during evaluation.
Feature Details
GET / POST / DELETE Per-location method control via allow_methods
Static file serving HTML, images, CSS, JS with correct Content-Type
Directory listing autoindex on generates HTML listing with XSS protection
File upload multipart/form-data and raw body, stored in upload_store
Redirects return <code> <url> — 301, 302, 307, 308
Custom error pages 400, 403, 404, 405, 413, 500, 501, 502, 503, 504, 505
client_max_body_size 413 returned when body exceeds limit (supports K/M/G suffixes)
Path traversal protection /../ sequences detected and blocked with 403
CGI execution fork() + execve(), env vars: REQUEST_METHOD, QUERY_STRING, CONTENT_LENGTH…
Non-blocking CGI Output read via poll() on pipe, server never blocked
CGI timeout 7-second watchdog — kills process, returns 504
Virtual hosting Multiple servers on same port, matched by Host header
Location matching Longest prefix wins; ~ .ext$ for extension matching
Root inheritance Location inherits server-level root and index if unset
Multiple ports Each server block binds its own socket, shared if same host:port
