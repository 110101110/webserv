POST — File Upload
POST Multipart upload → /upload
/upload ↗
Filename auto-filled in the Delete field after a successful upload.
Terminal
# Create a test file and upload it
$ echo "Hello webserv!" > /tmp/test.txt
$ curl -sv -F "file=@/tmp/test.txt" http://localhost:8080/upload/test.txt

Terminal

CGI — Non-Blocking Proof
AUTO TEST Infinite CGI + parallel static request

Fires /cgi-bin/infini.py (infinite loop) then 400 ms later sends GET /. The static page responds immediately — server is not blocked. CGI gets killed after the 7-second watchdog → 504.

Terminal — open 2 tabs
# Tab 1 — launch the infinite CGI (will hang ~7s then get 504)
$ curl -sv http://localhost:8080/cgi-bin/infini.py

# Tab 2 — immediately test that the server still responds (should be instant)
$ curl -sv http://localhost:8080/
MANUAL Individual CGI scripts
Terminal
# Infinite loop → 504 after ~7s
$ curl -sv http://localhost:8080/cgi-bin/infini.py

# Sleep 10000s → 504 after ~7s
$ curl -sv http://localhost:8080/cgi-bin/sleep.py

# Malformed CGI output → 500
$ curl -sv http://localhost:8080/cgi-bin/bad_cgi.py

# Valid CGI → 200
$ curl -sv http://localhost:8080/cgi-bin/hello.py
Error Handling
Trigger HTTP error responses
Terminal
# 404
$ curl -sv http://localhost:8080/does-not-exist

# 413 — sends 11 MB body (limit is 10 MB)
$ dd if=/dev/zero bs=1M count=11 2>/dev/null | \
  curl -sv -X POST -H "Content-Type: application/octet-stream" \
       -H "Content-Length: 11534336" --data-binary @- \
       http://localhost:8080/upload/bigfile.bin

# 405 — DELETE on a location that only allows GET
$ curl -sv -X DELETE http://localhost:8080/html/index.html

# 403 — trying to DELETE a directory
$ curl -sv -X DELETE http://localhost:8080/upload/
