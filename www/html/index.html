AUTO TEST Infinite CGI + parallel static request

Fires /cgi-bin/infini.py (infinite loop) then 400 ms later sends GET /. If the server is truly non-blocking the static page responds immediately while the CGI is still pending. The CGI gets killed and returns 504 after the 7-second timeout.
